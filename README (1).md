
# RockPaper Scissors Game

A fun and simple Rock-Paper-Scissors game built using HTML, CSS, and JavaScript. The game lets users play against the computer.


## Features

- User vs Computer gameplay
- Random computer move generation
- Keeps track of scores
- Responsive design for desktop and mobile


## Demo

https://pruthviraj75.github.io/Rock_Paper_Scissors_Game/


## Tech Stack

Built With:

- HTML5  
- CSS3  
- JavaScript  

## Used By

- Choose between Rock, Paper, or Scissors.
- The computer will randomly pick one as well.
- The winner is displayed along with the updated score.
